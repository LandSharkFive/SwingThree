# SwingThree

**SwingThree** is a high-performance C# .NET 10 backtesting engine and strategy analysis platform designed for evaluating swing trading algorithms against historical market data.

## Key Features

* **Advanced Strategy Suite:**
  * **Moving Average Crossovers:** Identify trend direction and trade setups using configurable Fast/Slow SMAs.
  * **Dynamic Trailing Stops:** High-watermark percentage-based trailing stops and initial stop-loss management to protect unrealized gains and limit downside risk.
* **Performance Metrics:** Built-in calculation of starting/ending capital, win rate percentage, profit factor, average gains/losses, and maximum drawdown.
* **High-Speed CSV Data Ingestion:** Optimized parsing pipeline to quickly load and process daily or intraday historical price bars from CSV files.
* **Modern .NET 10 Architecture:** Leverages latest framework capabilities, memory-efficient data structures, and clean separation of concerns for fast execution and parameter sweeps.
